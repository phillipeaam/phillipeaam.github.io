    Selected contributions

    Pathless was our three-person entry for Brackeys Game Jam 2026.2. I invited a childhood friend and my sister to join me for a lighthearted break from work; neither had prior experience with game development or related fields. I developed key gameplay and mission systems, with player setup and scene work shared across the team.

    • Radio scanning architecture: I implemented the proximity scanner and HUD using ScriptableObject definitions for signal ranges. A Unity Awaitable loop samples sources and maps distance to discrete strength levels; the scanner communicates proximity rather than direction or triangulation.
    • Survivor and mission flow: I implemented survivor interaction and assistance, then integrated mission progression, extraction, restart, and results reporting. C# events and delegates connect mission state to rescue accounting and the report. The calamity baseline and main-scene assembly include shared work.
    • Player setup and scene tools: I configured and integrated the third-party Starter Assets controller, input actions, and mission triggers. ProBuilder was part of collaborative scene work.

  5. Wallace’s Quest

    An isometric-style tactical game where grid positioning, attack range, and turn order shape each encounter.

    Role:
    Game Engineer
    Type:
    Tactical turn-based RPG
    Period:
    Aug 09–Aug 24, 2020
    Context:
    Game Demo
    itch.io
    See more

    Selected contributions

    I built the turn-based combat loop, a grid-pathfinding module, and a data-driven weapon-area system.

    • Turn ownership and action completion: A central manager tracked turn order while player and enemy units handled their own action sequences and signaled completion. Death events triggered configurable stage checks for victory or defeat.
    • Grid pathfinding and movement range: The module reads obstacle cells from a Tilemap, builds a rectangular walkability map and a four-neighbor node graph, then supports route and reachable-area queries.
    • Configurable weapon areas: ScriptableObject assets store each attack area’s relative grid cells and damage multipliers. The module copies the offsets, rotates them for a requested cardinal direction, and translates them to a target grid position, preserving the authored data.

    Technology

    • Unity
    • C#
    • uGUI
    • Unity Tilemap
    • ScriptableObjects
